# Модуль Core

Общее ядро backend: то, чем пользуются все предметные модули и что не принадлежит ни одному из них - идентичность пользователя, коды ошибок, локализация контента, персистентность, шина сообщений.

Здесь же живут демо-срезы `Ping` и `Notes`: они показывают сквозной путь и уйдут вместе с первым предметным модулем.
