# Архитектурный дизайн (arch-design)

Слой документации стадии планирования (design-time): целевой дизайн модулей и системы, который пишется до и во время реализации и служит основой для неё. Отвечает на вопросы "что построим" и "почему так".

Содержимое:

- Подпапка на модуль: `<module>-context.md` (бизнес-видение: назначение, требования, границы MVP) и `<module>-architecture.md` (технический дизайн: слои, компоненты, ключевые решения со ссылками на ADR), с C4-диаграммами в `diagrams/`. На текущем этапе проработан только [core/](core/core-architecture.md); предметные модули появятся вместе с их реализацией.

Связь с Diátaxis. arch-design - слой design-time; документация реализации по [Diátaxis](../../adr/0035-documentation-diataxis.md) - слой steady-state (пишется постфактум). Разведение по типу содержания: бизнес-видение и обоснование архитектуры ("почему") живут здесь и в ADR; справочник по факту (as-built), рецепты и учебник - в Diátaxis; Diátaxis `explanation.md` ссылается сюда, а не переписывает обоснования. Полное правило - [ADR-0034](../../adr/0034-documentation-lifecycle-layers.md).

Обзор уже собранного каркаса (стек, рантайм) - [../../architecture.md](../../architecture.md).
